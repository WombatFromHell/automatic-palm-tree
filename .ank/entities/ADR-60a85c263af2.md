"every other file in a feature directory is not a module" is true of the loader but false of the
tree: nixos-niri/_niri.nix, _niri-portals.nix and _niri-session.nix are modules imported by
nixos.nix, and nixos-kde/_theme.nix is imported by home.nix. Read literally, the rule forbids
exactly the pattern those features use, so a contributor would split or rename them.

The rule worth keeping is the discovery boundary: lib/features.nix only ever picks up the three
platform names, so an extra file cannot reach a host by itself. It arrives only where the platform
module imports it, which keeps the import visible in the feature's own entry point.
