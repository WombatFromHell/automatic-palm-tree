constraint: |
  A pinned binary release asset is repaired at build time with the format's own tool: the store interpreter is set on every executable the asset ships, the rpath on every shared object with no swallowed patchelf failure, a script shebang is repointed at the store bash, and its bin entries are always wrapped with the GPU driver directory and xdg-utils on PATH; a /lib64 or /bin path inside the store is a crash, not a fallback. Flags a module hands the derivation reach the wrapper through lib.escapeShellArg, and --no-sandbox throws at eval rather than disabling the namespace sandbox.
