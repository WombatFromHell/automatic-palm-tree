writeShellApplication exports PATH from runtimeInputs, so deps (jq, sops, age, ssh-to-age) go
there, not into a hand-built PATH. The script stays a file so it is testable on its own and so
nixpkgs' shellcheck runs on the text that ships (tests/shellwrap.nix builds the three wrappers).

A store path reaches the script by marker replacement (xilo.sh's __XILO_PROGRAM__ replaced with the
CLI's store path), which keeps the exec off PATH — PATH would find the wrapper itself. The escape
hatch for the helpers is env-var override, not a flag.
