autoDiscoverModules picks up hosts/<name>/nixos.nix and every home-<user>.nix, and enrichHost
unions them with what the record declares. The union is deliberate: a plain // dropped the
discovered home file whenever a host declared its own module for that same user.

A home-<user>.nix file also implies that user, so validateHost seeds users from the discovered
names and the user submodule fills the enabled/isAdmin/hmEnabled defaults. A file named
home-josh.nix.bak or josh-home.nix is invisible, which is why the name is the rule.
