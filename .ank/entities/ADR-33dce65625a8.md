mkUnitMounts returns lists, and systemd derives unit names from `where`, so combining groups with
// would drop a whole group's mounts. unitName is exported so a consumer names a unit exactly the
way mkUnitMounts does.

Sugar: a string entry means { what = it }; automount emits the paired .automount that the mount
requires and after; skipIfMissing adds ConditionPathExists. An empty option list is dropped so
NixOS defaults apply, which keeps /boot on vfat correct.

shortcut: unitName assumes paths without - or special characters; use
utils.escapeSystemdPath (the NixOS module arg) if a mount point ever needs them.
shortcut: skipIfMissing is checked once at unit start, so a device plugged in later needs a unit
restart.
