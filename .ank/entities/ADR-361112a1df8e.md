hosts/methyl/home-josh.nix and hosts/methyl-nixos/home-josh.nix open with `with pkgs.unstable`,
which the old wording read as the set reading itself. It does not: the body still reaches packages
through pkgs.unstable.flakePackages.<name>, and the with-binding is scope sugar over those members.
Forbidding it would force a name prefix on every reference without preventing a self-read.

lib/default.nix#unstableFor still builds the set from nixpkgs-unstable with baseOverlay only, and
the self-read prohibition - the thing that actually deadlocks or double-evaluates - is unchanged.
