A package read is a value, so it goes through the package set; a module *path* cannot be a value
(`imports = [inputs.sops-nix.homeManagerModules.default]` runs before eval), so it goes through
the `inputs` specialArg. Both members land in every set this file builds.

A derivation that imported lib/pin-meta.nix itself, or read inputs directly inside a derivation,
breaks the boundary and stops the tests from building it against the production set.
