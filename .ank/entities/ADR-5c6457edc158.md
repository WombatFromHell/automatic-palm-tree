Host discovery imports hosts/<name>.nix or hosts/<name>/default.nix through lib/hosts.nix
validateHost, which evals it against lib/host-options.nix only: system, isNixOS, users,
features, nixosModules, homeModules, isQemuVM. Nothing in a host file is NixOS config.

The error context names the file and the fix, because the module system otherwise reports a
stray `boot` assignment as "option does not exist" against <unknown-file>, which no one can
trace back to the host they just wrote.

A newcomer's instinct is to write hosts/foo.nix as a NixOS module and list it as a profile.
That is the break this decision forbids.
