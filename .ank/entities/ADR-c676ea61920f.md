nixos-rebuild-ng sets NIXOS_INSTALL_BOOTLOADER itself and activates under `env -i`, so an env
prefix never reaches it — only the flag does. sudo's env_reset drops NIX_CONFIG for the rebuild too,
so the caches must be argv: --option survives env_reset and applies whether or not the invoking
user is a trusted user. Without them the first switch builds cache-fed paths locally, which is a
kernel compile and a firmware VM on a RAM-constrained laptop.

A `<user>@<host>` target uses home-manager switch instead, and that path requires the daemon to
have granted trust (nix store info says Trusted: 1), which bootstrap.sh --standalone arranges by
appending extra-trusted-users to /etc/nix/nix.custom.conf and restarting nix-daemon.
