disko exposes config.system.build.installTest (diskoLib.testLib.makeDiskoTest): it formats the declared disks in a VM, installs, reboots and verifies boot. That is a real build, so it cannot enter the eval-only gate (ADR-7d6e); it sits behind an app that runs one attribute through the existing bounded scope and reports peak= like tests/build-harness.sh already does. The VM renumbers devices to /dev/vda, so this proves layout and boot, never that a Windows partition survives.
