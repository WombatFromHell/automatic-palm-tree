buildHomeConfigurations emits "${user}@${host.name}", which is the key bootstrap.sh and
home-manager switch take. mkChecks filters by hostOf, so the filter and the key have to agree or
a home config silently gets no check.

Deriving the host some other way (a parallel map keyed by host) would leave checks and
homeConfigurations disagreeing about which host a name belongs to.
