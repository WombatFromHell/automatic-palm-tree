unstableFor gets baseOverlay alone (pinMeta + flakePackages), because it is injected as a member
of the set above it. Asking for itself would recurse through the overlay.

Feature packages read it as pkgs.unstable.yt-dlp; on a NixOS host the same member arrives via
nixpkgs.pkgs = host.pkgs, so nothing may import nixpkgs-unstable directly.
