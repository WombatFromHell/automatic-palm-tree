mergeHome forces isNixOS off, clears nixosModules and sets isAdmin false, then refuses any
nixos-* feature in the merged list. Dropping it quietly would leave a host half-configured and
someone would spend an afternoon wondering why the feature did nothing.

The home-only list lives in hosts/methyl-base/standalone.nix. A hybrid feature (hm-syncthing,
nixos-dmemcg) is allowed on both sides because it ships a home.nix.
