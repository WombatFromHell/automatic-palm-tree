features/nixos-automounts/nixos.nix publishes extraGroups.filesystems. The old text demanded the
feature name as the key. Nothing needs that: what matters is that each feature owns a distinct key,
so the merge at modules/defaults/nixos.nix cannot clobber another feature's group. The group name a
host sees is a name the feature chose, and renaming the key to nixos-automounts would rename the
group users get without changing any behaviour - no test asserts a key today.

If you prefer the literal rule, the code change is one line and this amendment is not needed; that
alternative was left unrun because it renames a group for no gain.
