Re-prefetching release assets is expensive and only meaningful for small source archives, so sri
pins compare versions and nar pins verify hashes. `./update.sh` with no argument updates when a
newer version is discoverable and otherwise verifies a nar pin.

Prefetch happens before metadata.json is written, so a failed fetch leaves the pin intact, and
meta_set rewrites through a temp file so a half-written metadata.json never lands.
