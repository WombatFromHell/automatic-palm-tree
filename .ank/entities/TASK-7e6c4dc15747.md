features/nixos-niri/_wl-watcher.nix:30: wl_watcher.py shells out to bare niri, pgrep and nvtop from
the session PATH, and systemd user units on Nix get no PATH into the store. niri arrives via the
feature's systemPackages; pgrep and nvtop are absent, so the backend falls back to
XDG_CURRENT_DESKTOP and the GPU-strict filter falls back to permissive. That degradation is silent,
and the hooks the watcher fires are the ones that decide whether gamemode runs.
