caches.nix owns nix.settings.extra-substituters and extra-trusted-public-keys, so gating is
membership (config.flakeCache.ready) rather than a flag a host flips. required is an attrset
keyed by cache so several features merge by key instead of last-wins.

A cache required but not enabled is a warning that names the cache and the fix, because the real
symptom is a slow build: substitution is opportunistic (nix.extraOptions fallback = true), so
whatever that feature pulls is built locally. A cache is only usable once the live /etc/nix/nix.conf
carries its key, so the switch that ships the key builds locally and the next one substitutes.
