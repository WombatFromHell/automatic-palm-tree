lib/hosts.nix keys discovery by the entry's own name and refuses two entries that resolve to
the same name (hosts/foo.nix beside hosts/foo/). Before the guard, the later entry silently
overwrote the earlier one, so a host disappeared from the flake outputs with no error.

A newcomer adding a flat file next to an existing directory host is the break this forbids:
rename one, do not let discovery choose.
