features/nixos-cachyos/nixos.nix and features/nixos-niri/_spicy.nix gate on enable membership, not
ready. That is not a hand-flipped flag: both read the registry. ready answers "every cache this
host requires is enabled", which is the wrong question for a feature that needs one cache - a host
with cachyos enabled and another required cache missing would still be usable for cachyos builds.

The single-writer rule holds unchanged and modules/caches.nix#requiredNames still enforces it; only
the gating clause needed widening so the two existing forms are both legal.
