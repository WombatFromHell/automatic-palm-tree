Formatting and linting the whole tree was a hand-run one-liner (`fd -g "*.nix" -0 | xargs -0 alejandra -q; statix check`), so it only happened when someone remembered it, and it resolved fd, alejandra and statix from whatever the host profile happened to install.

`apps.<system>.style` makes it one command whose tools come from the flake's own nixpkgs through writeShellApplication's runtimeInputs, the same way apps.cache-check ships lib/cache-check.sh. The pipeline itself lives in lib/style.sh, so shellcheck lints the shipped text (ADR: shipped shell is linted whether or not writeShellApplication wraps it) and tests/outputs.nix asserts the app shape and the script's contents.

The shell half joined the same app rather than becoming a second command: every `.sh` and `.bats` goes through `shfmt -w -s -i 2` then shellcheck, with shfmt and shellcheck added to the same runtimeInputs. `.sh` is checked strictly. The `.bats` pass excludes only SC2154, SC2030 and SC2031, because shellcheck's dataflow never runs bats's `setup()`/`teardown()` and therefore reads every variable they assign as unset, or as a modification lost in a subshell. Everything else bats raised was real and is fixed in the file: a `cd` that must abort the test (SC2164), deliberate single quotes marked with directives (SC2016), and a `! grep` replaced by a count assertion (SC2314 -- a `!` only fails a Bats test when it is the last command).

Markdown joined last, through oxfmt rather than prettier or dprint. It needs no config file (defaults are the house style), selects its own files and honours `.gitignore`, so it is the only pass in the script with no `fd | xargs`, and a positional `'!.ank/'` excludes the decision corpus without adding an ignore file: ank addresses entity content, and oxfmt rewrites emphasis, escapes literal `*` and formats YAML front matter, so formatting `.ank/` would rewrite decisions. `--no-error-on-unmatched-pattern` keeps an empty tree from exiting 2. Nix and mermaid are not languages oxfmt knows, so `nix` fences in the design docs stay verbatim and alejandra remains the only nix formatter. The one house-style change it made is `*emphasis*` becoming `_emphasis_`, plus table re-padding -- both stable on a second run.

It is deliberately not a tests/run.sh step: the formatters rewrite files in place, and the gate asserts on evaluated values without mutating the working tree (ADR-7d6e: eval-only and memory-capped).
