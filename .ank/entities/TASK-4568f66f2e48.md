lib/features.nix:47 admits the guard reads the host's feature list only: a kernel module imported
through a host-local nixosModules file bypasses it, and the module system then reports
"boot.kernelPackages is defined multiple times" with two store paths and no host name. That is the
exact failure the guard exists to prevent, arriving unlabelled.

hardware-configuration.nix sets kernelModules, never kernelPackages, so no host trips it today;
the fix is to check the module paths the builder assembles, not just the feature list.
