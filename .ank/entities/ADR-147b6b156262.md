Forcing one to follow ours would evaluate it against a rev its CI never built, so every path it
publishes from its cache stops matching: the CachyOS kernel and KaiT2en's kernel and firmware
would rebuild locally, on the host with the least RAM. The same holds for the cache urls in the
registry, which are somebody else's build of their own rev.

Only home-manager, dms, dcal and nixgl use follows, and each follows a tree we do evaluate.
