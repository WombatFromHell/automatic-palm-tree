Retires ADR-5eb78b01a869, whose text reads "whose first line is ," - the marker literal was dropped when the entity was created, so the rule no longer names the contract the gate enforces. Its amendment ADR-dcf30409fc01 stays accepted and states the marker correctly; this entity carries the same rule so the damaged wording stops binding. --supersedes names one document, and edit cannot repoint it, so the pair cannot be retired by a single entity; retiring the amendment too would add a second binding copy of the same rule.

Measured: tests/run.sh:237 reads line 1 of each guard and cuts `# expect: ` off it, then matches the substring against the thrown error (:239, :245); all 13 tests/red/*.nix guards carry the marker. A contributor following the damaged text could ship a guard with no marker and the gate would compare an empty string, which matches any error.

No code change: the guards and the parser already agree. The tryEval clause stands unchanged - builtins.tryEval cannot gate a deferred error in this Nix.
